## 三、本轮新发现（R5-1 ~ R5-3）

### R5-1 【应改】表11 两列 σ_ROC 的实际计算口径与式(8) 的 σeff 定义冲突（R4-5 的残留）

- **位置**：表11（P110）与说明段 P109；式(8) 与 P105 的 σeff 定义。
- **现象**：P109 称"表中 σROC 一列按**式（8）**计算：解耦前取 σ = 3.0 ℃、解耦后取 σ = 2.0 ℃"。而式(8) 定义为 σr = √(2λ/(2−λ))·**σeff**/W，且 P105 明确 **σeff ≈ 0.670σ**（3 点中值滤波方差削减比 0.4487）。
- **证据（独立复算）**：
  - 若**严格按式(8)** 取 σeff = 0.670σ：
    - 解耦前（σ=3.0）四窗口复算 = **0.799 / 1.682 / 4.031 / 8.359**，表值 1.194/2.512/6.035/12.522，**比值恒 1.494~1.498**；
    - 解耦后（σ=2.0）复算 = **0.637 / 0.641 / 0.620 / 0.637**，表值 0.956/0.961/0.930/0.955，**比值恒 1.499~1.501**。
  - 若取 **σeff = σ**（即不乘 0.670）：
    - 解耦前复算 = **1.193 / 2.510 / 6.018 / 12.478**，与表值 1.194/2.512/6.035/12.522 **比值 1.000~1.004** ✅（残差来自等效窗口 71.1/33.8/14.1/6.8 的舍入）。
- **性质**：表11 两列的实际自变量是 **σeff 本身**（取值 3.0/2.0），而文中把它叫作"σ"并声称"按式(8) 计算"。读者若按式(8) 自带的 σeff≈0.670σ 定义代入，两列都会小 1.5 倍。**列头写 σ_ROC、正文写 σ=3.0/2.0、式(8) 却要求 σeff=0.670σ——三个符号在同一处碰撞。**
- **说明**：该项较第 4 轮已有**实质改善**（第 4 轮是"整列偏大 1.50 倍且无任何声明"，本轮已声明两列口径差 1.5 倍并给出 σ 来源），但**绝对值仍未与式(8) 的 σeff 定义对齐**，属"半修复"。
- **修改建议（二选一，1 行可改）**：
  1. 在列头或表注把自变量改名为 **σ_eff**（解耦前 σ_eff = 3.0 ℃、解耦后 σ_eff = 2.0 ℃），并声明"此处 σ_eff 指判据有效噪声（解耦前含滤波不一致放大、解耦后为滤波后噪声）"，即与式(8) 的 σeff 一致；**或**
  2. 若确要用 σ（滤波前）为自变量，则将四值改为按 σeff=0.670σ 复算的 **0.80/1.68/4.03/8.36** 与 **0.64/0.64/0.62/0.64**，并核对"解耦后稳定于 59.1~61.1 s"的表述（该窗口稳定性本身不受影响）。

### R5-2 【应改】4.2 节"固定 1 s 周期（2.678 MB/d）"与"节省 85.5%"基准不一致

- **位置**：P82（4.2 节）。
- **现象**：同句既引"较固定 1 s 周期（**2.678 MB/d**）节省带宽 **85.5%**"，又引"1% 时节省 89.1%"。
- **证据（独立复算）**：
  - 固定 1 s 周期、异常率 0% 的日流量 = 31×86400/1024² = **2.5543 MB/d**（与表6 P=1、0% 一致）。
  - 以 2.554 为基准：1 − 0.3704/2.5543 = **85.50%** ✅（与论文 85.5% 一致）；1 − 0.2784/2.5543 = **89.10%** ✅。
  - 以文中括号值 **2.678** 为基准：1 − 0.3704/2.678 = **86.17%** ❌（≠ 85.5%）。
  - 即 85.5%/89.1% 均严格来自 **2.554**，而括号里的 2.678 与二者不匹配（2.678 亦不等于表6 P=1 异常 5% 的 2.682）。
- **性质**：孤值（非本轮引入，R3 及更早已存在），不影响结论，但与同句其它数字不自洽。
- **修改建议**：将括号内"2.678 MB/d"改为 **2.554 MB/d**（与表6 P=1、0% 一致）。

### R5-3 【应改】公式编号 (1)~(13) 断裂：σr 公式标签为 (8)、却被引为式(10)；(10) 号缺位，(11)(12)(13) 为行内
