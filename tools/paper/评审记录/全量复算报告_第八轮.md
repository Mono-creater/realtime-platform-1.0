## 四、本轮发现的问题与处理

### R8-5【已撤回】—— 原判为"Wilson 示例不自洽"，复核后确认**论文正确、我的复核有误**

**第八轮当时的判断（错误）**：正文 §3.3 写"例如'零缺口'（0/100）…95% 置信区间上界为 3.7%"，我用一段 Python 实现算出 0/100 上界 = 1.87%、3.7% 对应 0/50，据此判定论文用了 Wilson 却报出别的方法的数，并改为"（0/50）…3.6%"。

**第九轮复核（撤回该结论）**：上段 Python 实现有缺陷——Wilson 上界的平方根项漏除了 `n²`。按论文式(12) 所给的标准 Wilson score 区间重算：

```
[p̂ + z²/(2n) ± z·√( p̂(1−p̂)/n + z²/(4n²) )] / (1 + z²/n)
p̂ = 0, n = 100, z = 1.96
  → z²/(2n)            = 0.019 208 0
  → z·√(z²/(4n²))      = 1.96 × 0.009 800 = 0.019 208 0
  → 上界 = (0.019208+0.019208) / 1.038416 = 0.036 995 ≈ 3.70%   ← 与论文完全一致
```

交叉核对：Clopper-Pearson 0/100 = 3.62%；rule of three = 3.00%；**Wilson 0/50 = 7.14%**（故"3.6%"亦不成立）。

**处理**：`apply_revisions26.py` 已将正文恢复为"（0/100）… 上界为 3.7%"。
**教训（已沉淀）**：复核公式必须与论文所引方法**同一标准形式**；单侧数值差异应先怀疑自己的实现，再怀疑论文。

§4.4 末句"本文方法在零误报约束下将 3 ℃/min 缓变检出时延缩短至 **60 s**"——系第 7 轮 60→61 s 统一时的遗漏（表9/摘要/英摘/结论均已改 61 s）。
