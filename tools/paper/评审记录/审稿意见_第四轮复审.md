**但本轮把核查重心从"格式一致性"下沉到"公式—正文—数值的三方数学自洽"后，发现了一批此前各轮均未触及的实质性问题**，集中表现为：

## 二、本轮新发现的问题清单

### R4-1 【严重】式(8)(9) 的噪声边界对本文实现不成立，且与 4.4 节实测自相矛盾

- **位置**：4.4 节 P102—P106（式(8)(9) 及"σ ≤ 0.704 ℃"）；摘要 P1/P5；结束语 P122 结论(3)；2.4 节 P63（式(10)）；表10。
- **现象**：
  1. 式(8) `σROC = √2·σeff/W` 用**相邻差分**估计变化率，W 取 60 s（=1 min）；式(9) `3σROC ≤ rw`，rw = 2 ℃/min。论文明确说式(8)是"保守上界"，实际实现是用**最小二乘斜率**（式(10)）。
  2. 由式(9)反解得 σ ≤ 0.704 ℃，并被摘要、结论(3)、4.4 节三处引用为"变化率判据的噪声适用边界"。
  3. 4.4 节 P94 称"σ_W 升至 2.0 ℃ 时 5.5% 试验出现告警，**与式（9）适用边界 σ ≤ 0.704 ℃ 相符**"。
- **证据（独立复算）**：
  - 式(8) 代入 σ=1.0 ℃：σROC = √2×0.670×1.0/1 = **0.9475 ℃/min**（论文写 0.947 ✅），3σROC = **2.84 > rw = 2**。即**在 σ=1.0 ℃ 时，按式(8)(9) 本应判超限**，而表8 却称 σ_W=1.0 ℃ 纯噪声误报为 **0**。
  - 式(10) 代入 σ=1.0 ℃（n=61, Δt=1 s, λ=0.2, σeff=0.670σ）：σr = √(12/(61×(61²−1)))·σZ/Δt = **0.0974 ℃/min**（σZ 用中值滤波后 σ），3σr = 0.29 ≪ 2；若 σZ 用**未滤波** σ=1.0（即 √(0.2/1.8)=0.3333）则 σr = **0.1454 ℃/min**（论文"0.145"✅）。**这说明论文的 0.145 事实上把中值滤波的 σeff 缩减"漏掉"了**——式(10) 的 σZ 到底用滤波前还是滤波后噪声，定义缺失，二者相差 √0.4487≈1.49 倍。
  - 用"与实现一致的"最小二乘式(10) 复算 σ_W=2.0 ℃：3σr = **0.585 ℃/min ≪ 2**，即**几乎不应产生告警**；而用式(8) 差分估计：3σROC = **5.69 ≫ 2**，即**几乎必然 100% 告警**。两种口径都推不出"5.5% 试验告警"。
- **性质**：三套数字（式(8) 边界、式(10) 实现、4.4 节实测）互不封闭。**"σ ≤ 0.704 ℃"这一被反复引用的边界，既非本文实现的边界（实现边界远更宽松），也无法预测实测的 5.5%**。这是本文第三创新点"误报率由经验设定转为可理论计算"的核心论证，此处不闭合则该贡献不成立。
- **修改建议**：
  1. 明确式(10) 中 σZ 的定义（滤波前还是滤波后），并在 2.4 节、式(8) 处统一说明。
  2. 要么以式(8) 为**唯一**声明边界并**据此解释** 4.4 节实测（则 σ_W=1.0 不应误报为 0，需重新说明为何 3σ=2.84>2 却 0 误报）；要么以式(10) 为实际控制限、把 σ ≤ 0.704 ℃ 改为式(10) 口径下的边界，并在 4.4 节给出**可复算**的 5.5% 推导（例如给出仿真设定中的告警判据实际阈值）。
  3. 删除或改写"与式（9）适用边界 σ ≤ 0.704 ℃ 相符"这一句——目前它**在数学上不成立**。

### R4-2 【应改】式(12) 带宽公式在异常率 5% 处代入值与公式不符

- **位置**：4.2 节 P81（式(12) `B = 31·[(1−λ)/Pn + λ/Pa]`）。
- **现象**：论文称"以 Pn = 10 s、Pa = 1 s 为例，**异常率 5% 时平均带宽 0.388 MB/d**、告警时延约 0.5 s，较固定 1 s 周期（2.678 MB/d）节省带宽 **85.5%**；异常率 1% 时节省 **89.1%**"。
- **证据（独立复算）**：
  - 式(12) λ=0.05：B = 31×(0.95/10 + 0.05/1) = 31×0.145 = 4.495 B/s → 日流量 = 4.495×86400/1024² = **0.3704 MB/d**，**≠ 0.388**。
  - λ=0.01：日流量 = **0.2784 MB/d**（论文未给绝对值）。
  - 节省比例：1 − 0.3704/2.5543 = **85.50%** ✅；1 − 0.2784/2.5543 = **89.10%** ✅。
  - 四处数字中，**只有 0.388 与公式不符**，而 85.5%/89.1% 都严格来自公式。故 0.388 系手改/不同前提（如误用 2.68 或 31×0.15/1024²×86400 之类）遗留的孤值。
- **修改建议**：将"0.388 MB/d"改为 **0.370 MB/d**（或说明其所用的额外开销假设）。同一段其余数字已自洽，一处订正即可。

### R4-3 【应改】式(13) Wilson 区间公式漏写中心修正项 z²/(2n)

- **位置**：4.3 节 P87（式(13)）。
- **现象**：论文写为
  `p̂ ± z·√(p̂(1−p̂)/n + z²/(4n²)) / (1 + z²/n)`。
- **证据**：标准 Wilson score 区间为
  `[p̂ + z²/(2n) ± z·√(p̂(1−p̂)/n + z²/(4n²))] / (1 + z²/n)`，
  即分子中心须为 **p̂ + z²/(2n)**，而非 p̂。论文式(13) 的分子缺 **z²/(2n)** 项（区间宽度的分母项正确）。
  - 以论文自举的"零缺口 0/100"复算：标准 Wilson 上界 = **0.0370 = 3.7%** ✅（与论文一致）；而按论文**印刷的**式(13)（无中心项）上界 = **0.0185 = 1.85%** ❌。
  - 即"公式写错、代入数值用的是对的公式"，属抄录遗留。
- **修改建议**：将式(13) 更正为 `(p̂ + z²/(2n) ± z·√(p̂(1−p̂)/n + z²/(4n²))) / (1 + z²/n)`，并注明 p̂=k/n。数值 3.7% 无需改。

### R4-4 【应改】"16 位寄存器逐样本上传约 19 倍"与其脚注"19.2 kbit/s"数值矛盾

- **位置**：表6 脚注 P85；摘要 P1/P5；结论 P120。
- **现象**：脚注称"若以现场 PLC 可实现的 16 位寄存器逐样本上传（**单机约 19.2 kbit/s**、含序号）为基线，双包协议相对其压缩约 **19 倍**，其中 10 点滑窗降采样贡献约 10 倍、按需追读贡献约 1.9 倍（10×1.9=19）"。
- **证据（独立复算）**：
  - 双包 2 s 轮询日流量 = 1.2772 MB → 等效带宽 **2.40 kbit/s**。若相对基线压缩 19 倍，则基线应为 **24.27 MB/d ≈ 2.40×19 = 45.6 kbit/s·?** → 精确地 2.40×19 = **45.6 kbit/s**；而论文脚注同时给出基线为 **19.2 kbit/s**。二者**相差 2 倍**：19.2 kbit/s 对应压缩比 **154.8 倍**，不是 19 倍。
  - 若按"3 通道 ×100 Hz、16 位（每样本 2 B）"的朴素算法：3×100×2 B×86400 = **49.44 MB/d**，相对 2 s 双包（1.2772 MB）为 **38.7 倍**，也不是 19 倍。
  - 19.2 kbit/s 的来历可反解为"3 通道×100 Hz×8 B/样本"（=300×64 bit/s），即**每样本已含 8 B 传输开销**——与"逐样本 16 位寄存器"（每样本 2 B 数据）不是同一口径。
- **性质**：同一条脚注内"19.2 kbit/s 基线"与"19 倍压缩"两个数字来自不同假设，不能同时成立。且"10 倍×1.9 倍=19 倍"的分解是**乘积拼凑**，与 19.2 kbit/s 无推导关系。
- **修改建议**：统一为**一个**明确基线（建议：3 通道×100 Hz、每样本 2 B 有效数据 + 明确的分帧开销假设），并令"基线速率—日流量—压缩比"三者可互相复算；删去"10×1.9=19"的拼凑表述，或给出其严格推导。

### R4-5 【应改】表11"解耦前 σ_ROC"整列系统性偏大 1.50 倍，口径未声明

- **位置**：表11（P108）；式(8)。
- **现象**：表11 给出解耦前 σ_ROC = 1.194 / 2.512 / 6.035 / 12.522 ℃/min（Δt = 1000/500/200/100 ms，等效窗口 71.1/33.8/14.1/6.8 s）。
- **证据**：按式(8) `σROC = √2·σeff/W`（σeff=0.670，W 以 min 计）代入各等效窗口：
  - 71.1 s → **0.800**；33.8 s → **1.682**；14.1 s → **4.032**；6.8 s → **8.360**。
  - 论文值/复算值 = 1.492 / 1.493 / 1.497 / 1.498——**四行完全同比例 ≈ 1.495 ≈ √2.233**，说明表11 用了与式(8) 不同的噪声设定（例如 σ 取 1.5 ℃ 而非 1.0 ℃，或 W 单位换算差异）。
  - 解耦**后**列（0.956/0.961/0.930/0.955）与式(8)（W=1 min → 0.947）吻合 ✅，说明解耦后列没错，**仅解耦前列与式(8) 不同源**。
- **修改建议**：在表11 或正文注明解耦前 σ_ROC 所用的 σ 与窗口单位（与式(8) 是否同口径）；若同口径则应改为 0.80/1.68/4.03/8.36。**表内列与正文公式必须同源**，否则审稿人无法判断"解耦前后对比"是否公平。

### R4-6 【建议】端到端时延"平台引擎路径增加约 2P"与自身数据不符

- **位置**：4.5 节 P111。
- **现象**："平台引擎路径因叠加中值滤波与连续确认，时延增加约 **2P**，2 s 轮询下均值为 **5.00 s**。"
- **证据**：同段给出边缘路径 2 s 轮询均值 2.00 s、95 分位 2.90 s；引擎路径 5.00 s。5.00 − 2.00 = **3.00 s = 1.5P**（P=2 s），而非 2P = 4 s。若"约 2P"指引擎路径叠加量，则应为"约 1.5P"；若指引擎路径总时延，则 5.00 = 2.5P 亦非 2P。三种解读均不吻合。
- **修改建议**：把"约 2P"改为与数据一致的口径（如"较边缘路径增加约 1.5P"），或补充 2P 的来源推导。

### R4-7 【建议】式(9) 前置句"则控制限应满足。"为残句

- **位置**：4.4 节 P104。
- **现象**："按 3σ 准则，若要求单点越限概率不超过 0.3%，**则控制限应满足。**"——句末缺宾语，且式(9) 独立成行在其后，语义断裂。

### R4-8 【建议】式(5) 的 W 单位与 roc 量纲未在本式内封闭

- **位置**：2.4 节 P57—P59（式(5) `roc = (x(t) − x(t−W))/W`）。
- **现象**：同一段既称"W 为统计窗口，本文取 **60 s**"，又称"roc 的量纲为物理量每分"。式(5) 中若 W 以 s 代入，roc 单位为 ×10⁻²… 实为"每 s"，与"每分"不符；必须 W **以 min 代入**才是"每分"。公式未标注 W 的单位约定，且与"取 60 s"的表述并列时易生歧义。
- **修改建议**：在式(5) 符号说明中明确"W 以 min 计（本文 W=1 min）"，或写为 `roc = 60·(x(t)−x(t−W))/W`（W 以 s 计）。**这是本文唯一一处量纲表述不封闭的公式**（其余如式(8) 已隐含 W 以 min 计，但同样未显式声明）。

### R4-9 【建议】式(10) 与式(8) 的统计量口径未在正文中区分清楚

- **位置**：2.4 节 P63（式(10)）、4.4 节 P104（式(8)）。
- **现象**：式(8) 用**差分**估计、式(10) 用**最小二乘**估计，二者"σ"是否含中值滤波缩减、W/n 单位是否一致，全文未统一声明。R4-1 已列出由此引发的数值冲突。此处单列，是因为**即使 R4-1 的数值问题被订正，公式符号系统仍需补一次统一说明**，否则读者无法自行复算任一个 σROC/σr。
- **修改建议**：在 2.4 节末加一段符号约定：σ（滤波前原始噪声）、σeff（中值滤波后）、σZ（EWMA 后）、W（min）、Δt（s）、n（窗内样本数）、λ；并声明式(8) 是**保守上界**、式(10) 是**实现所用**。这一处补写可一次性解决 R4-1 与 R4-5。

### R4-10 【建议】"1%～10% 区间 MAE ≤ 0.33 百分点"的点估计与 Wilson 口径并列易致误读

- **位置**：4.3 节 P87—P88、摘要。
- **现象**：文中由点估计给出 MAE ≤ 0.33、又由 Wilson 给出 0/100 → 上界 3.7%。两者含义不同（点估计精度 vs 小样本置信上界），摘要仅提 MAE，结论(3) 仅提 MAE，未点明"零缺口时点估计为 0 但上界 3.7%"这一更有工程意义的结论。
- **修改建议**：在结论或摘要中补一句"零缺口场景下 95% 置信上界为 3.7%"，使"可考核口径"这一卖点更突出。非必改。
