# PLC 程序下载清单（台架实测 V2.1）

配套文件：

| 文件 | 用途 |
|---|---|
| `plc-program/Bench_Main.st` | 完整 ST 程序（协议 + 本地循环 + 安全），直接粘进 AutoShop |
| `plc-program/Bench_Main_指令表.md` | 循环/安全块的梯形图指令表，逐网络录入用 |
| 本文件 | 替换、导入、下载、验证的步骤 |

> AutoShop 的工程文件（.hcp/.hcpp）是私有格式，无法在外部生成。
> 做法：新建工程 → 新建 ST 程序 → 粘贴 `Bench_Main.st` → 编译下载。

---

## 1. 五个软元件替换

打开 `Bench_Main.st`，把下面 5 个占位符换成实际地址。默认建议按 GL10-4AD + 本体 AO：

| 占位符 | 默认建议 | 说明 |
|---|---|---|
| 温度通道元件 | `AIW0` | GL10-4AD CH0，4~20 mA |
| 压力通道元件 | `AIW1` | GL10-4AD CH1 |
| 湿度通道元件 | `AIW2` | GL10-4AD CH2 |
| 比例阀输出元件 | `AQW0` | 本体 AO CH0 → 比例阀 |
| 升弓机构输出元件 | `AQW1` | 本体 AO CH1 → 升弓机构 |

**必须核对**：在 AutoShop 的“软元件表/模块配置”里看 GL10-4AD 的起始软元件。若你的工程把模拟量映射到 D 区（如 D100/D101/D102），就把占位符换成对应 D 寄存器，不要照抄 AIW。

## 2. 新建与导入

1. AutoShop → 新建工程 → 机型选 **Easy320**（与实际 CPU 一致）。
2. **编辑器选 LiteST**（AutoShop 里的结构化文本就叫 LiteST）。这样主程序 MAIN 就是 ST，直接粘贴，不用建子程序、不用 CALL。
3. 全选 `Bench_Main.st` 内容粘贴进 MAIN。

> 如果工程已经建成梯形图：工程树 → 程序 → 右键“插入子程序” → 名称 `SBR_BENCH`、类型 ST → 粘贴 → 在 MAIN 里加 `LD M8000 / CALL SBR_BENCH`。
>
> **LiteST 限制**：不支持 `Arr[n]` 变量下标、不支持数组写入。本版程序已改成 30 个标量移位寄存器，不用数组、不用 FOR。若编译仍报数组相关错误，把报错发我。
4. 编译（F7）。应无错误；若有，见第 6 节。
5. 模块配置：添加 GL10-4AD，CH0/1/2 设为 **4~20 mA**。
6. 以太网：IP 与平台同网段（如 192.168.1.88），掩码 255.255.255.0。
7. MBS 服务：端口 **502**、unit **1**、4xN ↔ DN 直接映射，保存后重启 PLC。

> 若工程里已有 `Easy320_main.st` 的协议程序，不要两份都下载。
> 用 `Bench_Main.st` 替换它（它已包含同样的协议块，并多了循环与安全）。

## 3. I/O 接线

| 端子 | 接什么 | 逻辑 |
|---|---|---|
| X0 | 启动按钮 | 常开，按一下启动本地循环 |
| X1 | 停止按钮 | 常开，按下停止 |
| X2 | 急停 | **常闭**，正常导通，按下断开 |
| X3 | 模式开关 | 0=远程（平台写 2022）；1=本地循环 |
| Y0 | 升弓指示/方向阀（可选） | 本地升弓时 ON |
| Y1 | 降弓指示/方向阀（可选） | 本地降弓时 ON |

- 若执行机构只用比例阀（AO CH1），Y0/Y1 可以不接，仅作指示。
- X2 接成常开会导致本地循环一起动就停，务必确认。

## 4. 下载后验证（不接平台，先用 ModbusPoll）

按顺序做，每步通过再下一步：

| 步 | 操作 | 通过判据 |
|---|---|---|
| 1 | 上电，PLC RUN | RUN 灯常亮，ERR 不闪 |
| 2 | ModbusPoll 读 4x2001—2005 | 三路为工程量；2004 bit6=1；2005 每秒 +1 |
| 3 | 写 4x2022=100 | 弓到下限附近；AO 约 10.1 mA |
| 4 | 写 4x2022=1400 | 弓到上限附近；AO 约 18.9 mA |
| 5 | 写 4x2021=2500 | 气囊压力约 250 kPa（看标准表） |
| 6 | 写 4x2022=1300 | 停在工作高度附近 |
| 7 | X3 拨到 1，按 X0 | 本地循环启动：升 20 s → 顶保 60 s → 降 20 s → 底保 60 s |
| 8 | 循环 1 次后按 X1 | 停止，弓回 100 mm，Y0/Y1 全灭 |
| 9 | 按 X2 | 立即停止，两个方向都断 |

> 第 3—6 步同时验证了 G6 的写回读通路。

## 5. 与平台联调

1. X3=**0**（远程）。
2. 平台 `.env`：`PLC_MODE=real`、`PLC_HOST=<PLC IP>`、`PLC_PORT=502`、`PLC_UNIT_ID=1`、`PLC_INTERVAL=1000`。
3. 启动平台 → `node bench/run.js preflight`。
4. 全 PASS 后，平台写 2022，PLC 只做协议与 AO 输出。
5. 若要平台跑 G3：`node bench/run.js lift --profile g3 --base 100 --amp 1300 --cycles 30 --yes`。

## 6. 常见编译/下载错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 编译报“未定义标识符 温度通道元件” | 占位符没替换 | 按第 1 节替换 |
| 编译报 `REAL_TO_INT` 类型不匹配 | 表达式不是 REAL | 确认 `avgT * 10.0` 带小数点 |
| 编译报数组越界 | `ARRAY[0..9]` 与 FOR 不一致 | 保持 0..9、FOR 0 TO 9 |
| 下载后 2005 不跳 | SM4010 不是 100 ms | 查特殊继电器手册，换实际位 |
| 2004 只有 0x00 | 程序没跑或 MBS 映射错 | 重新下载；查 4x2001 映射 |
| 写 2021 无反应 | MBS 只读或程序每周期覆盖 | 查 MBS 写权限；确认程序只读 D2021 |
| AO 不跟随 | 输出软元件写错 | 核对 AQW 地址与模块通道 |
| 本地循环不动 | X3=0 或 X2 常开 | 拨 X3=1；查 X2 常闭 |

2. 两路 AO 是 `AQW0/AQW1` 还是别的软元件？
